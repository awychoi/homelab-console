## What it is

A local-first Mac app for managing Raspberry Pis and Git repos. Monitor fleet, preview and deploy Docker Compose changes over SSH, and roll back failed updates. Review and commit changes, push to GitHub, and mirror repos to Gitea. No cloud account or Pi agents required.
